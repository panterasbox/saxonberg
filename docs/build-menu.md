# Build menu — pick a build by how much you've got tonight

This is not a backlog. Backlogs get ordered by *priority* (an opinion you
stop believing) or by *area* (which doesn't match how you decide), and
then they get abandoned. This list is ordered by **size**, because the
real question at the start of a session is *how much time and brain do I
have right now* — and that axis doesn't go stale.

"Big" is two things bundled: **build volume** (how much code) and
**design-openness** (how much undecided thinking). An end-of-night pick
wants both *low* — mechanical, already decided. A day story wants
design-openness *high* — that's the fun. The tiers are tagged
accordingly.

Every item rides shipped substrate unless noted. Full detail on any pick
is one click away in the by-area reference, [slates/README.md](./slates/README.md);
this file is just the menu. Cross items off as they ship; add new ones at
the tier that fits. Sizes are rough — move anything that feels mis-tiered.

For the *priority* axis this menu deliberately isn't: the
**[launch-worklist](./launch-worklist.md)** (the guild-derived
economy gap list — what must exist before launch, readiness-tagged).
