# Capability magic core — code-verified phased implementation plan

The effect substrate + casting: magic = spend a reserve → fire declarative effects → they land in shipped systems. Traces to [capability-magic-requirements.md](../requirements/capability-magic-requirements.md) (authoritative) and [capability-magic-slate.md Part IV](../slates/deferred-rpg/capability-magic-slate.md) (the locked model); verified against build-3 code on `feature/capability-magic` (citations are `file:line` under `packages/server/src/mud/` unless noted).

## 1. Grounding facts established from the code

**Condition/inflict surface (InjectChannel's backing).** `api/condition.ts`: `InflictSpec = EnergyInflictSpec | ShockInflictSpec` (95), a discriminated union on `mechanism`. `EnergyInflictSpec` (53-72) carries `mechanism: Exclude<InsultKind,'shock'>` + `site` + `energy` — and **`heat` is already a `Channel`** (the fire build landed the insulation fold), so a magical heat injection at a body is `ConditionApi.inflict({mechanism:'heat', site, energy})` **with zero new spec kind**. The inflicter is context-derived (`ExecutionContextApi.getActingAuthor`, `api/condition.ts:22-26`) — the caster attribution is automatic from the command frame. `InflictOutcome` (98-103) returns `{trauma, afflicted}`.

**Materials-response shape (the resist seam's origin).** `api/material.ts`: `attenuate` (174) folds one covering layer, `resolveTrauma` (200) gates at tissue, `severityToBand` (236) bands. Crucially, **the whole channel-axis fold is already packaged behind `ConditionApi.inflict`** — `ConditionLogic.inflictThroughStack` resolves the covering stack outside-in, folds `attenuate`, gates via `resolveTrauma`. The channel axis needs *no* new fold code and *no* MaterialApi refactor (see DIV-1). The toxin instance: `seeds/lib/metabolism/conditions/alcohol.yaml` authors `toxinBehavior.bands` (ascending `{threshold, severity}` cutoffs) that `Metabolic` reads live against the burden — the authored-bands precedent the mental axis copies.

**Conditions substrate (Afflict/Relieve + the modifier's home).** `lib/vitals/Condition.ts`: `ActiveCondition = AfflictionRecord | Trauma | SustainedShock` (179) — a **closed three-kind union**. `Trauma` carries `mechanism?` (92) and `inflictedBy?` (98) — the provenance tag lands as a sibling field. `AfflictionRecord` (37-45) is `{kind:'affliction', templatePath, stage, elapsed}` — its stage is written by an owning driver (metabolism toxin bands `Metabolic.ts:733-781`, respiration `Respiration.ts:535`), **it has no self-driven evolution**. `SustainedShock` (161-176) is the exemplar for adding a kind: new interface + its own reconcile arm in `VitalsMixin.reconcileConditions` (`Vitals.ts:573-707`, arms for trauma 602-626 and shock 633-671, with first-touch/linkdead/far-past stamp guards). `afflict`/`relieve` are dumb list mutators (`Vitals.ts:780-791`); `hasCondition(pred)` (776) is the query. Kind-A `Condition` Idea leaves are seeded as pure data (`class: /lib/vitals/Condition`, the alcohol/collapse/asphyxiation seeds) — dread and overchannel-strain follow this exactly.

**Reserve substrate (mana).** `lib/reserve.ts`: `Reserve` is a value class with decomposed-scalar persistence; `ReservedMixin` (139-202) carries the keyed Record — `setReserve(new Reserve(key, capacity, current, theme, floorEffect))` installs any authored reserve; `adjustReserve(key, delta)` (167) clamps to `[0, capacity]`. Biological reserves are `%`-unit capacity-100 (106-119) with `floorEffect` names driving the metabolism cascade (`Metabolic.reconcileCascade` 688+, with hysteresis clear) — the overchannel-strain install/clear copies that cascade shape. **The module's own doc names magic reserves as the intended second instance** (8-13): theme + key, never a fork.

**Metabolism coupling (Serenity recovery).** `Metabolic.coupledRecovery` (`Metabolic.ts:635-680`): gain = `MAX_RECOVERY_PER_MIN × stepMin × POSTURE_BASE[posture] × restQuality × hydrationThrottle × spo2` — but it is **hard-coded to `endurance` paid by satiation/hydration**; there is no theme-pluggable recovery step (DIV-6). The protected reads (`currentRestQuality()`, posture base) are reachable from a mixin composed *above* `MetabolicMixin` in the class chain.

**Species / faculty.** `lib/species/Species.ts`: `vitalProfile: VitalProfile | null` (202) is the flat-nested-record precedent (no marshaller, JSON-free persistence, 196-201); `innateMixins` (230) intrinsically *activates* a gated mixin composed on the shared class — resolved by `MixinApi.getActiveMixins` (`api/mixin.ts:347`, innate leg documented 1353-1401) and checked via `MixinApi.isActive(stuff, 'FooMixin')` (374). **Playable species seeds live in the content pack** `packages/content/species-and-names/content/lib/species/animalia/.../homo/*.yaml` (DIV-5), where `sapiens.yaml:14` authors `vitalProfile` — `facultyProfile` rides beside it. Composition: `Creature` composes `ReservedMixin`/`VitalsMixin`/`MetabolicMixin` (`lib/creature/Creature.ts:105-125`); `Character` adds `EngagedMixin` (89) and `AdvancementMixin` outermost (`lib/character/Character.ts:84`).

**Advancement (the grid).** `lib/advancement/Discipline.ts`: pure-data leaf Idea at `/lib/advancement/Discipline/<key>`, durable `key` ≠ templatePath, typed `requires`/`specializes`/`synergizes` edges (100-105) + band-gated `conferrals: ConferralRule[]` (`{band, verbs}` 53-56). Seeds at `seeds/lib/advancement/Discipline/*.yaml` (18 exist; `awareness.yaml`/`blades.yaml` are the templates); `DisciplineCatalogue` harvests every leaf at boot (seed `seeds/obj/DisciplineCatalogue.yaml`, warmed via `bootstrap.ts:53-59`). Bands: `untrained → novice → competent → proficient → expert` (`CompetenceBand.ts:21-35`), `AdvancementApi.bandFor(owner, discipline)` async, bands-only (`api/advancement.ts:120`); `recordSignature(owner, {subchecks:[{discipline,difficulty,outcome}…]})` (84) explodes one act into per-Discipline rows — a cast credits verb + noun as two subchecks of one signature. `AdvancementMixin` re-pushes `conferredVerbs` onto the affordance stack on every append (`Advancement.ts:58-73`).

**Activity (the cast engagement).** `EngagedMixin` slots `body|hands|attention|voice` (`lib/activity/Engaged.ts:66`); a durative activity is a small class implementing `DurativeActivity` with pinned `onComplete`/`onAbort` closures, started via `SchedulerApi.start(activity)` (`api/scheduler.ts:159`) — `SearchActivity` (`lib/concealment/SearchActivity.ts`, effect-at-completion, abort = nothing happens) and `HazardActivity` (`lib/hazard/HazardActivity.ts`, one class two types, the body-slot **pin**) are the templates. Barge-in reasons ride the `AbortReasonRegistry` declaration-merge (`Engaged.ts:56-64`).

**Actuation targets.** `FireApi.ignite`/`tryAutoignite` (`api/fire.ts:64/75`), `ThermalApi.depositHeat(stuff, joules)`/`reconcilePhase` (`api/thermal.ts:59/73`); `ElectricityApi.conduct(source: Stuff & Energized)` (`api/electricity.ts:74`) and `shockContact(source, victim)` (101) — the source must compose `Energized` (a potential-holding node, `lib/electricity/Energized.ts:31`), and `conduct` resolves the graph **of the source's location**, faction-blind. `Disguisable.setDisguise(disguise|null)` (`lib/disguise/Disguisable.ts:36`) is the transient *imposed* semblance — the Cloak backing. `LightSourceMixin.setEmittedFlux` (`lib/perception/LightSource.ts:151`) with the environment witness hook; hosts are Things (a candle), **not Characters** (DIV-8). `BulkableApi.transfer(from: BulkSlot, to, amount)` (`api/bulk.ts:202`) with the **unbounded-source** debit-skip (documented at 199) — `UnboundedSourceMixin` (`lib/bulk/UnboundedSource.ts`) is the inexhaustible water the conjure draws from; `floorSurfaceNear` (228) is the no-vessel spill target. `StuffApi.clone` (254) + `ContainmentApi.move` (135) for Conjure-of-Stuff. Combat's `shove` gambit sets `flagOnLand:'prone'` (`lib/combat/Gambit.ts:109-116`) — it does not displace (DIV-9).

**Suppression walk.** `Zone.lookupField<T>(field)` (`lib/zone/Zone.ts:95-130`) is the **async** field-inheritance walk (own value → enclosing zone recursion), reached from a room via `ZoneApi.resolveZoneForPath` (`api/zone.ts:128`). The biome outward containment walk (`BiomeLogic.ts:457-524`, sync `getContainer()` chain with depth guard) is the room-tier precedent. The async/sync split matters: the condition reconcile is sync (DIV-4).

**Command machinery.** Categories are **directory-discovered** (`CommandLogic.ts:309` `readdirSync(CMD_DIR, {recursive:true})`) — a new `cmd/magic/` needs no registration. Validators: sync body + optional async **preload** threading back via `allowed` (`lib/command/validators/requiresGovernor.ts` pattern); `requiresConscious.ts` shows the condition-reading refusal shape. YAML arg validators per `cmd/combat/attack.yaml:35`.

**Catalogue precedent.** `obj/CorpoCatalogue.ts` / `obj/DisciplineCatalogue.ts`: singleton Idea + `PostRegistrationMixin`, transient caches keyed on durable key, warmed in `postRegister` from leaf templates (never cloned live), `canEvict` veto, seed `{class: /obj/X, data:{}}`, `bootstrap.ts` manifest entry. `SpellCatalogue` is this shape verbatim.

**Dials + tests + demo.** `config/app-settings.yaml` (725 lines); `backend/__tests__/AppSettingsSeeder.test.ts:44` asserts `added === 220` — any new dial bumps it. Test scaffolding: reconcile-on-read tests need a `HasInteractiveMixin` occupant registered on the ConnectionManager (else linkdead-freeze re-stamps and integrates nothing — `domain/hearthworks/__tests__/hearthworks.integration.test.ts:40` `TestOccupant` precedent); sustain tests must not `StuffApi.clearAll()` mid-scenario. Demo: `seeds/domain/hearthworks.yaml` — a self-contained `CartesianZone`, rooms with `adornments:`/`populates:`, **no inbound exit, teleport-reachable** ("the treeline reachability precedent"), integration-tested by direct construction (the faked-Mongo no-clone-pipeline pattern).

## 2. Divergences from the requirements' assumptions (flagged)

- **DIV-1 — the N-axis resist fold needs almost no new engine.** The requirements frame "the materials-response shape generalized to N axes" as a build item. In code, the **channel axis is already fully packaged** behind `ConditionApi.inflict` (fold + gate + banding internal), and **toxin** is already the metabolism banding. The only *new* resolver is **mental** (Composure). Resolution: no new `lib/` fold engine and **no MaterialApi refactor** — a small `Resist` vocabulary value-object in `lib/magic/` (axis names, `ResistSpec`, the mitigator/substrate shapes) + an axis dispatcher inside `MagicLogic`: `channel → ConditionApi.inflict` (delegation, MaterialApi untouched), `mental → resolveMentalResist` (new, mitigator fold structurally present but empty v1 + Composure `factor()` × authored bands), `toxin → recognized, not wired` (no v1 toxin spell), `none → land`. The generalized shape is documented in `magic.md`; immunity-as-limit is a fold test.
- **DIV-2 — modifiers need a fourth `ActiveCondition` kind.** `ActiveCondition` is a closed 3-kind union; Kind-A afflictions have no self-driven evolution and no dormancy notion. The modifier ("installs a condition the reconcile-on-read drivers realize, drops under suppression") requires a new `SustainedEffect` kind + its own arm in `VitalsMixin.reconcileConditions` — exactly how electricity added `SustainedShock`. Additive edit to shipped `Condition.ts`/`Vitals.ts`, not a fork.
- **DIV-3 — provenance fields don't exist beyond Trauma.** `Trauma` has `mechanism`/`inflictedBy`; `AfflictionRecord` has neither. Add optional `magicOrigin?: MagicProvenance` (`{verb, noun, spellId, caster}`) to `Trauma` + `AfflictionRecord` (+ required on `SustainedEffect`). Plain-scalar JSON — persists free through the `conditions` collection, no marshaller.
- **DIV-4 — the suppression walk is half async, but the dormancy check must be sync.** `Zone.lookupField` is async; `reconcileConditions` is sync. Resolution: the room-tier read is a **sync outward containment walk** (the `BiomeLogic` chain-walk shape) over a declared `suppressesMagic` field on `Location`; the zone tier folds in **async** at the two async seams — the cast-time validator preload and a cached-restamp on the `SustainedEffect` record (`_suppressionCached` + async re-resolve, the `Thermal.lastAmbientK`/`restamp` precedent). The warded practice room works entirely on the sync tier.
- **DIV-5 — playable species live in the content pack, not mud seeds.** `config/char-gen.yaml:6-10` points species at `@saxonberg/content-species-and-names` (`packages/content/species-and-names/content/lib/species/**`). Authoring `facultyProfile` + `innateMixins: ['CasterMixin']` edits the pack, not `seeds/`.
- **DIV-6 — mana recovery can't literally ride `coupledRecovery`.** It is hard-coded to endurance/satiation/hydration. Resolution: `CasterMixin` (composed on `Character`, *above* `MetabolicMixin`) runs its own `reconcileFaculty()` reconcile-on-read using the **same protected reads** (`currentRestQuality()`, `POSTURE_BASE`) and stamp guards — same shape, zero Metabolic edits, "recovery follows rest/calm via metabolism" holds honestly.
- **DIV-7 — spark needs an `Energized` source Stuff.** `conduct(source: Stuff & Energized)`; the caster composes no `Energized`. Resolution: the shock executor mints a transient energized locus (clone `/lib/magic/SparkSource` — a tiny `EnergizedMixin(Thing)` template — `ContainmentApi.move` it to the target's container, set voltage, `conduct()`, `StuffApi.destruct`). The caster standing in the same pool is bridged and shocked — the caster-obeys-physics acceptance test falls out of the real graph.
- **DIV-8 — glowlight can't be a flux on the caster.** `Character` composes no `LightSourceMixin`. Resolution: glowlight = **Conjure a bound emitter** (a `/lib/magic/GlowlightOrb` `LightSourceMixin(Thing)` clone placed in the caster's location) + a `SustainedEffect` condition on the caster holding the orb's path; the reconcile arm realizes it by pull — active → flux on, **dormant (suppressed) → flux 0**, relieved (dispel/expiry) → destruct the orb. The lit-brazier contrast in the warded room is `FireApi.isBurning` continuing untouched.
- **DIV-9 — combat's `shove` doesn't displace.** `flagOnLand:'prone'` only. The `Move` executor uses the honest pieces directly: shove = prone via the posture surface (+ optional one-exit displacement via `ContainmentApi.move` when an open exit exists behind the target); pin = the `HazardActivity` **body-slot hold** precedent (a timed engagement, `hazard-pin`-shaped). No combat machinery edits.
- **DIV-10 — naming collision: `obj/Casting.ts` is taken** (the thermal cast-metal solid). The cast activity is `CastActivity` (`lib/magic/CastActivity.ts`); nothing in this build may claim the bare name `Casting`.
- **DIV-11 — conferral confers *verbs*, not spells.** `ConferralRule.verbs` are yaml paths pushed as affordances. Per-spell access must therefore be a **band gate at cast time** (`MagicLogic` compares `bandFor(caster, verb)` and `bandFor(caster, noun)` against the spell's authored `requiredBand` — competence IS access), while the `cast`/`spells` **verbs** are afforded by `CasterMixin.commandContributions` (the `EngagedMixin.cancel` precedent), so a species without the faculty never sees the verb. This satisfies both requirement lines with the shipped mechanisms.

## 3. Hard spots, with recommended resolutions

**H1 — mana as an absolute avail/max Reserve (revised 2026-07-23).** The
first cut pinned mana at `%`-capacity-100 (the biological shape), which
forced Depth to scale *effective cost* — a conceptual inversion (a deep
mage got discounts, not a bigger pool) and it collapsed the Depth×Serenity
orthogonality (a fixed-size tank refills the same regardless of depth).
Revised: `Reserve` natively stores capacity + current as real `Quantity`s,
so mana goes **absolute** — **Depth derives capacity**
(`capacity = magic.depthCapacity.<band>`, e.g. 80/120/180 `pt`, installed
from the species profile), **spell costs are absolute points**, **Serenity
scales an absolute recovery rate** (`pt`/game-min by band), and **% is
derived** (`current/capacity`) wherever a fraction is wanted (the Composure
`factor()`'s `manaFraction` reads it unchanged). Overchannel deficit is
absolute points (`severityPerDeficit` scaled accordingly). All still
derive-on-read from the profile — capacity is stamped at install (and
re-derived on faculty reconcile), never an independent stored scalar (the
binding constraint). `theme:'arcane'`, `floorEffect:'overchannel-strain'`,
installed idempotently by `CasterMixin` on first faculty touch, only when
the faculty is active. **Cost: one new dimensionless `Unit` — `'pt'`** (one
union member + one ops-table row in `lib/quantity.ts`). Not a gamey
intrusion: the Reserve header itself promises authored magic reserves
("charge"/"essence") as instances, and every one of them needs a non-`%`
unit — `'pt'` is the substrate's own missing piece, named neutrally
because "mana" is a content word barred from the engine surface.

**H2 — Composure as a live factor.** `FacultyProfile = { depth: Band, serenity: Band, composure: Band }` (a small 3-band record on `Species`, the `vitalProfile` field pattern; band vocabulary in `lib/magic/Faculty.ts`). The mental resolver reads `factor = composureBase(band) × (magic.composure.floorFactor + (1 − floorFactor) × manaFraction)` — a drained mage resists worse; a non-caster species reads a neutral authored default (Composure exists without the casting faculty). Stage = authored ascending bands on the dread condition seed (the toxin-`bands` precedent) evaluated against `intensity − mitigations`, scaled by `factor`.

**H3 — the cast activity + cost model.** `CastActivity` holds `hands` + `voice` for `spell.castSeconds` (somatic + verbal; speech-blocking is the legible interrupt vector), `cancelable`, effect-at-completion (the `SearchActivity` shape). **Cost is spent at completion, in the same beat the effects fire; an aborted cast spends nothing and fires nothing** (the minimum the requirements bind; a `magic.abortCostFraction` dial ships at 0 as the tuning seam). **Overchanneling** = completing a cast whose effective cost exceeds current mana: allowed, drives mana to 0, and afflicts `overchannel-strain` (stage from the deficit, `magic.overchannel.severityPerDeficit`), which degrades casting (a cast-time stage-read penalty on cast speed/potency) until the metabolism-shaped hysteresis clear (mana recovering past `magic.overchannel.clearThreshold` relieves it — the `reconcileCascade` clear precedent).

**H4 — the suppression value + walk.** `lib/magic/Suppression.ts` value-object: `MagicSuppression = { all: true } | { verbs?: string[], nouns?: string[] }` (absent field = no filter). Carried as a declared persisted field `suppressesMagic` on `Location` (getter/setter + `persistentFields`, authored in room seeds) and readable zone-tier via `lookupField('suppressesMagic')`. `MagicApi.suppressionAt(place)` = sync containment walk (depth-guarded, the `BiomeLogic` shape); `MagicApi.suppressionAtDeep(place)` = the async version folding the zone chain (used by the validator preload and the `SustainedEffect` restamp). Grid filtering compares the cast's `{verb, noun}` against the filter — "no ·Fire here" blocks `firebolt`, not `glowlight`.

**H5 — dispel/detect keyed to the tag, never past it.** `Relieve` executor with `tagKeyed: true` scans the target's `getConditions()` for entries whose `magicOrigin` is present (optionally cell/caster-filtered), relieves those (destructing any bound emitter), and **refuses** anything without the tag — the "dispel refuses a non-magical condition" AC is a direct filter, structurally unable to touch a laceration. `Sense` tag-keyed = the detect read over the same field.

**H6 — where the cast-time suppression veto lives.** A spell-agnostic `requiresUnsuppressed` **validator** (async preload → `suppressionAtDeep`, sync body refusal) vetoes *any* cast inside an `{all:true}` field with the legible refusal; the **grid-filtered** case needs the parsed spell, so it resolves inside `MagicLogic.cast` (before any spend) with the same prose shape. Both are cast-time; modifiers going dormant is the reconcile's job, and impulse consequences are never reverted (the lit brazier keeps burning — nothing to do, which is the point).

**H7 — dread's evolution.** Dread lands as a Kind-A `AfflictionRecord` (`/lib/magic/conditions/dread`, authored seed with `observableSigns` + mental bands) stamped `magicOrigin`, onset stage from the mental resolver. Its evolution v1 is **timed decay owned by the magic arm** of `reconcileConditions` (stage decrement per `magic.dread.decayPerSec` of game time, cleared at 0) — the smallest honest driver; richer signatures are content later. It is an **impulse** — suppression never touches it.

## 5. Cross-cutting constraints honored (checklist)

- **The governing invariant, structural** — `Effect` is a closed union in `lib/magic/Effect.ts`; every executor bottoms out in a shipped gated Api; `Script` is `isWizard`-gated; the Phase-4 seed-validation test makes an unbacked effect unrepresentable. ✔
- **Caster obeys own physics** — spark = the real conduction walk from a real `Energized` node (DIV-7); firebolt = real `depositHeat`/`tryAutoignite` + the shipped fire tick; no caster exemption anywhere. ✔
- **Never fork Reserve / no stored CON scalar** — mana is a `ReservedMixin` instance (H1); Depth/Serenity/Composure are `FacultyProfile` bands + derive-on-read factors, never stored on the creature. ✔
- **Bands, never numbers** — `spells`, refusals, and the faculty view speak `CompetenceBandName`s and prose; another's Composure surfaces only as outcome. ✔
- **Actor from context** — the caster is the command-frame giver; `inflictedBy` stamps via `getActingAuthor` untouched. ✔
- **No new module categories** — mixin (`Caster`), value-objects (`Grid`/`Effect`/`Resist`/`Faculty`/`Suppression`), data-Idea (`Spell`), catalogue singleton (`SpellCatalogue`), gated Api pair (`MagicApi`/`MagicLogic`), activity class (`CastActivity`, the `SearchActivity` category), command YAML+controller, validators, seeds, declarative domain content. Nothing free-floating. ✔
- **No new ticks/events** — recovery, strain, dread decay, modifier realization, and dormancy all ride reconcile-on-read; the cast rides the activity substrate; suppression is a read. ✔
- **Suppression honesty** — dormancy only un-realizes `SustainedEffect`s; impulses have no suppression code path at all. ✔
