Engagement · three candidates

A reason to come back that isn't a streak.

GitHub's grid works for a reason worth copying carefully: it is a record of work, not an attendance sheet. Nobody is rewarded for opening GitHub — they are shown what they built. It is compelling because it is honest, and it would be worthless if it counted logins.

Which suits this game unusually well, because the game is about work — mining, nursing, law, smithing — and its progression model already says competence comes from doing the job. So the strongest candidate is not a new mechanic. It is rendering something you already record.

Standing is already a rate that decays. That is a return-hook you shipped without drawing it. Rendering the curve is more honest than inventing a streak, because the pressure it shows is real — the dip is a fortnight that actually happened.

And it recovers. The line coming back up is the part worth showing: the game does not hold a grudge, it just stops counting while nobody sees you.

The risk is tone. Rendered as a falling line with a red number, this becomes a guilt meter. It should read as weather, not a bill — which argues for showing it on the character panel rather than the front door.

A game with a public record can offer something no live-service game can: proof that a thing you did is still there. Not a badge the game minted for you — an entry in the Gazette, a measure you carried, a page still cited.

That is the deepest hook of the three and the slowest to pay off. It needs a world with history in it, so it is worth designing now and shipping once there is a year of record to draw on.

On day one this reads as an empty trophy case, which is worse than not having it. The practice record fills in from the first session; the chronicle needs the world to be old.

WHAT NOT TO BUILD
A login streak

Rewards opening the tab rather than doing anything, and a broken streak is a reason to stop entirely. It would also directly contradict standing, which measures what you did.

A season pass

Manufactured scarcity in a game whose premise is that its economy is real and its politics are earned. The tonal mismatch would be doing more damage than the retention is worth.

Minted achievements

The game already grants recognition that other people can see and dispute. A parallel private badge set would cheapen the real one.
