Convention · unbuilt states

What to render when the server can't answer yet.

A demo that wipes nightly buys a lot of latitude — nobody expects their character to persist. It buys none for showing a number the server did not produce, because a plausible fake is indistinguishable from a bug, and the one claim this game makes above all others is that its figures are real.

So the rule is narrow and absolute: never render a figure the server did not send. Everything below is how to say so without the interface looking broken.

Three states that look nothing alike
live the server answered
PLAY 74

Normal rendering. No stamp, no hatch, nothing to explain. This is the only state that gets to show a number.

empty answered, with nothing
PLAY —

A real zero. Korrin has never been taken out, so — is the truth and deserves a reason, not a stamp.

not wired no endpoint yet
RENOWN ╌╌

Hatched ground, dashed border, ╌╌ in place of the value. The layout is real so it can be judged; the figure is visibly absent.

And the fourth, which is never shipped
never this a plausible fake
RENOWN 31

It is not a fourth way of showing missing data — it is the absence of one. Nothing on it says the server was never asked, so it is indistinguishable from working: someone will screenshot it, quote the figure back to you, or file a bug when it never moves.

Which is why it sits apart from the three above rather than beside them. The others are choices about how to be honest; this one is the thing they exist to prevent.

What the agent should do, in order
1
Ship the surface, hatch the value

Default. The layout, the copy and the affordances are all judgeable without the number, and wiring it later is a one-line change rather than a redesign.

2
Cut the widget entirely

When the surface tells you nothing without its data — a chart, a leaderboard, a sparkline. An empty chart is worse than no chart, and the shelf already lets a player add it later.

3
Seed the world instead of the widget

If a figure must be live for the demo to make sense, put real content in the world so the real endpoint returns something. Slower, and the only version that survives contact with a screenshot.

✕
Hardcode a number that looks real

Including "just for now". It outlives the sprint, it gets demoed, and the first person to notice it never moves concludes the whole readout is theatre.

And in the world itself
Prose never hedges

A room description does not get a "not wired" stamp — that breaks the fiction to report an engineering fact, which is the wrong trade in the one place the game is supposed to be a world.

If a thing cannot be described yet, it is not in the room yet.

Commands refuse honestly

A verb the server does not implement should say so in the machine voice, not fail silently or pretend to work:

here› renown
not built yet — renown is designed but has no endpoint. try score
The demo says it is a demo

The front door already tells people the world resets nightly, framed as freedom rather than apology. One line there covers every placeholder in the build:

“Parts of this are drawn but not wired. Those are hatched, so you can tell what the game does from what it will do.”
