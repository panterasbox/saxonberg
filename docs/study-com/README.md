# The study.com tract

Twenty documents on the **education vertical** — the case for running
Saxonberg's model inside a working ed-tech business, and the design
work that would take.

⚠ **These talk about study.com directly and by name.** Several are
internal working docs written between us, not material to hand over;
each one says which it is in its own `**Status:**` line. Read that line
first.

Moved here from the `docs/` root 2026-09-06 — twenty files with a
common prefix was a directory wearing a naming convention.

## Start here

- [brief.md](./brief.md) — written to be handed to a study.com-side
  agent. The closest thing to an external-facing summary.
- [strategy.md](./strategy.md) — the between-us strategy. Internal.
- [platform-reality.md](./platform-reality.md) — verified ground truth,
  checked against the live stage database. Read before trusting any
  claim about what study.com actually does today.
