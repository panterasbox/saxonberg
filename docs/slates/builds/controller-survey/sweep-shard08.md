**Defects**
- OfferController 119: `context.note({reason: refusal})` puts `'sensed-bad'`/`'turned'` (Bonded.ts:178) into the response envelope, which goes over the wire to the client. The header's whole point (the food refusal never says why, so there is no free contamination detector) is defeated by any client that reads notes.
- ThrowAtController 78-84 with `Combatant.deliverThrown` (lib/combat/Combatant.ts:594, 603): on `wide` or `hit`, nothing moves the item. Only `ThrownLanding` (shatter/survive) does. "You hurl X… It goes wide." seems to leave X in your hand.
- ThrowController 22 / ThrowAtController: no `tryReleaseFromSlots` before the item leaves you. Give/Put/Drop/Get run that gate, so here a cursed item gets out and a phantom slot occupant stays behind.
- CourseController 88 and 229: `mayLeave` runs before the heading is resolved. With `--leaving-them` it writes the abandonment accountability record and calls `craft.leaveThem()` (clears `overboard`, Ship.ts:432). Then unknown-node, already-there, confined or a steer refusal declines. She never sailed, yet the abandonment is on record and the swimmers no longer block the next `course`.
- UnequipControllerBase 216-225: the `SchedulerApi.start` result is ignored. The comment at 115 says a strip stops when "the hands are busy", but `takeOff` never returns false for that. Each layer starts its own DressingStep, so a full strip likely costs about one layer's time. I did not check the scheduler's replace semantics.
- CoolController 114-123: its `findWater` lacks Rinse's Shore branch and `settle()`. At a shore you can `rinse` but `cool` says there's no water: drift between copies.
- LabelController 189: after a specimen has been minted and placed, a non-Labelled individual returns with no message and no note.

**Hard cases**
- Undress `pickDressed`: when no wound is named, it takes the most severe. Is a default that picks *which object the act changes* a choice about asking (presentation) or a world fact?
- Dose's "competent in medicine = licensed" judges a person (lens 7). Neither the controller nor Metabolic is its home. Whose is a permission that is really a civic criterion?
- Course readout (350-372) picks the position bracket by the navigation band. Is that presentation of a reading, or the epistemic rule itself (instrumentation's "competence resolves detail")?
- Offer: every food refusal gets the same sentence. Here the *vagueness* is the game rule, so a rewrite that words each reason creates a detector. Presentation cannot own a rule that consists of saying less.
- Sample: "here = where you stand" (the salting exploit) is a stated game rule that lives in a private controller method.

**Rules** (new)
- (12) *A verb whose act a sibling plan already tokenizes goes through that plan.* Evidence: Cool, Warm and Rinse hand-apply `cooling`/`warmth`/`rinsing`, the same tokens that `Vitals.treatmentPlanFor` and Treat's `REMEDY_WORDS` already carry. Three bespoke paths, one of them drifted.
- (13) *Every refusal precedes every write.* If the controller sequences checks and writes, a later refusal strands an earlier write. A plan that returns refusal-or-run makes this structural. Evidence: Course `mayLeave` (ledger + `leaveThem` before the node is resolved).
- (14) *When hiding the reason is the rule, the model returns an opaque refusal.* Withholding is not the sentence's job, because the note and the wire carry the reason anyway. Evidence: Offer 119.
- (15) *A view that splits text must not be un-split by the controller.* If the controller re-glues a preposition the binder consumed, the grammar is wrong. Evidence: Label 96-99 (`at …` put back into the label text).
