**Defects**
- SewController.ts:137 stamps `maker: maker.getTemplatePath()`. Every player shares one templatePath, so every garment a player sews carries the same maker (Spin/Weave already use `getIdentityPath()`).
- WeaveController.ts:79 refuses anything whose template path doesn't end `/yarn`: the path test SpinController's comment records as a shipped defect. A pack yarn under another path cannot be woven.
- GotoController.ts:84-89, 104-115: the comment says the raw fallback "checks and detaches" a coupled mover. No such code exists, and `ContainmentLogic` doesn't sever either, so a vetoed teleport plus fallback moves a hitched mover and leaves the hitch. Line 84 is also a broken sentence fragment.
- PackSyncController.ts:170-179 prompts for "a name" and passes the raw text to `PackApi.staff` as `memberPath`. Groups key on `/platform/agent/Avatar/<id>`, so a named maintainer is a member nobody matches.
- WizardController.ts:297: every message, success included, goes out on topic `shell.error`.
- PilotController.ts:52-69: the fee settles before `writeClaimsFor`. When n=0 the player has paid and is told "nothing to tell", with no mention of the coin.
- CloneController.ts:186: for copies 2..N, a destination error is ignored and the copy stays at a null container with no report.
- Scutch/Spin/Weave `finish`: if the mint throws after the input was consumed, the only trace is `console.warn`, and the player loses stock silently. Scutch prints "You get ." when every row fails.

**Hard cases**
- Tan's second `tan` as "check": is a verb whose repeat means *inspect* one act or two? (It saves a verb but hides the report behind a gate meant for an act.)
- Journey's ETA readout and "no road, but there's a sea; use `course`": wayfinding advice is presentation, but it needs the route model. Where does *explaining a refusal* stop being presentation?
- EngagedActController completes the act instantly, with no duration, for a non-Engaged giver. A base choosing that silently is a game rule, but every subclass relies on it.
- Copper/Harbor/Hide return finished sentences. Rule 2 forbids it, yet these controllers are then the cleanest in the shard. Is a `line` on a result tolerable when the controller can't do better?

**Rules (new)**
- (12) *An object that has the input in hand answers "can you X" itself; no controller tests a template path or duck-types a method.* Evidence: Weave:79 `endsWith('/yarn')`, Spin:270 `getYarnCount?.()`, Goto:268 `canTeleport` lookup.
- (13) *A completion that consumes input must report failure to the actor, not only the log.* Evidence: Scutch/Spin/Weave `finish` catch → `console.warn`.
- (14) *A verb with subcommands in its view never switches on `model.subcommand`.* Evidence: Player:32, Wizard:243 (Pack/Bank already split per D9).
- (15) *A typed value the view can type (number, enum, default) is not parsed in the controller.* Evidence: Bank `amount`/`count` as `string`→`Number()`, Borrow `for`, Paddle `WORDS`, PackSync `DEFAULT_PACK`.
- (16) *A permission dispatch is never re-implemented beside AccessApi, even "to mirror" it.* Evidence: Eval `holdsAuthority` 258-302, whose comments record two silent refusals caused by drift from `AccessRegistry`. Sharper than rule 11 because this is a leaf controller, not a base.
