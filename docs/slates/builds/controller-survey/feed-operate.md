**Hard cases (unclear) and the question each raises for a rule:**
- **Persistence capture (283-288).** If a replacement forgets it, the world silently loses state. *Is "make the change durable" coordination that every controller writes, or part of the mutation itself?* Feed suggests the mutator owns it.
- **The implicit source (162-174).** Picking "the first carried sack with compost in it" is a choice about asking (a default) *and* a rule about what counts as feed. *When a default encodes a domain filter, does the filter belong to the view (MQL) and only the fallback to the controller?*
- **The `already-fed` sentence picks wording off `slowAmendment`.** The wording depends on a game-rule fact. *Should a plan's refusal carry facts rich enough that the controller never recomputes the rule just to choose words?*

**Rules this controller suggests:**
1. **A refusal's condition belongs to the object, its sentence to the controller.** Test: could a rewrite change *when* the act is refused by editing only this file? If yes, the condition is misplaced. Evidence: 146-160, 215-251; the bug note at 202-207.
2. **Two controllers sharing a walk means the walk is the model's.** Test: does a "twin" controller copy the same target resolution? Evidence: `resolveGround` ≈ WaterController; `harvestPartFor` already on Soil.
3. **Numbers that convert matter into world state are never controller constants.** Test: would changing the constant change the economy? Evidence: `POINTS_PER_LITRE`, `creditDeed` difficulty.
4. **A default that filters by domain goes in the view.** Test: can it be written as an MQL `default:`? Evidence: `carriedFeedSource` vs operate.yaml's `kit` default.

**Hard cases (unclear) and the question each raises for a rule:**
- **"Most urgent first" (278-281) when `for` is omitted.** Is choosing the worst wound a choice about asking (a default a replacement could change to "ask me which") or triage, a medical fact? *Rule needed: when the object offers several valid targets, the object ranks them and the controller decides whether to pick or prompt.*
- **Self as the default patient (59).** It could be routing (`default: "me"`) or a policy (self-surgery allowed). *Does a default that changes who bears the cost count as presentation?*
- **The completion message lives inside the biology callback.** The engagement's callbacks mix world effect with talk. *Should a durative plan's `done` return facts, with the controller's narration subscribed to them, so a rewrite can change the words without touching `onComplete`?*

**Rules this controller suggests:**
1. **The engagement's callbacks are the model's; the controller only narrates them.** Test: does `onComplete`/`onAbort` mutate anything a `look` would show? If yes, it belongs to a model-side plan (the `ActPlan` shape `sowPlanFor`/`CoatPlan`/`ShapePlan` already use). Evidence: 151-207; OperationEngagement.ts's own header.
2. **A row field the controller re-hardcodes is a rule leak.** Test: grep the controller for a literal that duplicates a descriptor field. Evidence: `'medicine'` vs `op.competence.discipline` (101), `'formidable'` vs `op.difficulty` (187).
3. **A controller never writes another object's record fields.** Test: any `x.field =` / `x.field +=` on a non-model object. Evidence: 198-201 on `Trauma`.
4. **Zero-time fallbacks are rules.** Test: does a non-`Engaged` branch produce a different world outcome? Evidence: 209-212.
