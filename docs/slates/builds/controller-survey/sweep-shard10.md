**Defects**
- RackCheckController 79: `(item as Wieldable).isWeapon()` with no `isWieldable` check. The view only `requires: ChattelMixin`, and `Good` is Chattel but not Wieldable, so `rack check lantern` throws a TypeError instead of saying "isn't a weapon".
- Cp 61-65 / Mv 162-177 / Write 271-281: `AccessApi.can(giver, 'write', findByTemplatePath(dst) ?? null)`. `AccessRegistry.can` reads `zoneOf(null)` → `''` → untitled → false (AccessRegistry.ts:144-147). So a write to a path with no live instance, which is most new leaf rows, appears to always be refused. `canAtPath` is the path predicate built for this.
- ShelfConsign 173-180 vs HeldGoodsControllerBase 288-290: consign accepts a group-owned, org-chain-owned or unstamped-with-id good. Reclaim accepts only an exact player or house stamp. A good with a chattel id but no stamp is consigned unstamped (243 only stamps when there is no id) and then can never be reclaimed (`not-owner`). Likely.
- Layout 67-74: `save`/`list`/`forget` are routed before names, and `validateArrangementName` doesn't reserve them. `cockpit layout save list` saves an arrangement that can never be recalled.
- Rm 230-243: `-r` checks title on the root only, then deletes every descendant, including rows under a nested parcel someone else holds (suspected).
- Mv 191-196: a folder is moved as one row. Its descendants stay at the old path, under a deleted parent.

**Hard cases**
- The cockpit family (Card/Shelf/Style/Layout): self-dispatch exists because subcommands are one level deep. *Is "nested subcommands" a view feature the framework owes, or are these four controllers the sanctioned place for a second level?*
- Stand's water floor: the posture gate makes the controller do the surface's work. *When a security gate forces a rule into a controller, does the gate or the rule move?*
- Shell file verbs: authority is a game rule (who may write the world), but here it is a gate on a tool, not on a fiction. *Is tool authority "rule" (move it to the chokepoint) or plumbing every controller writes?* Write and the CMS disagreeing argues for the chokepoint.
- ShelfConsign 175-180: acting as the house, a hand may still consign their *own* good (`ownedBy(giver)`), with the payout going to the house. *Intended, or a copied clause?* The test can't tell.

**Rules (new)**
12. **The commit of a preference is the host's, not the verb's.** Test: do two controllers write → save → push the same keyspace? Evidence: the commit triple copied in Style 315-330, Shelf 419-430, Mode 141-180 and Layout 266-288, and the legacy `cockpit.layout` projection written by two of them.
13. **A vocabulary a verb validates against belongs to the schema of the thing it writes.** Test: does the verb hold a list it calls "the authority"? Evidence: Style 59 `KNOWN_THEMES`; Cockpit 389 already drifted from it once.
14. **A view that declares subcommands routes them, so a controller never re-switches on `model.subcommand`.** Evidence: Settings 47-61, Var 322-332.
15. **The binder tells a controller whether an arg was named or defaulted, so the controller never reads the raw query to find out.** Evidence: Buy 186.
16. **A validation that can be bypassed by a second door belongs at the door they share.** Test: does another entry (CMS, REST) reach the same writer without it? Evidence: Write 242-282 vs `saveTemplate` "the single chokepoint".
