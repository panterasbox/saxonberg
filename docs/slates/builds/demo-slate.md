## The demo cluster (blocks filming; each item names its consumers)

1. **Mock issuer adapter** — the credential-seam demo: a
   fixture/webhook emitting signed `lesson-completed` /
   `exam-passed` events (graded assessment-provenance per the seam
   correction) → claim/deed transcript evidence → conferral fires.
   *Unblocks V1's climax + V3's degree beat; IS the pitch demo
   (strategy doc model A); the seam + mock adapter was always the
   pitch plan.* The single highest-leverage build on this list.
2. **The demo world** — a curated, seeded, deliberately *aged*
   world-state as a permanent production asset: chronicle depth,
   chain-of-title history on props, named regulars with belief/
   recognition state, an aid post with patients, consignment
   shelves with real maker's marks, a stranger available to walk
   through a freshly published room. *Serves all five videos, every
   future live demo, and playtest staging.* Needs its own small
   design pass (what ages, how it's seeded, how it's reset).
3. **Threshold-ceremony beats** — the moments-entry micro-build:
   one designed, diegetic, Katie-grade beat each for the key, the
   first wage, and (first priority) **the conferral ceremony** —
   where in the University it lands, who speaks, what the room
   does. *V1's finale; V2/V3 reuse.*
4. **Aid-post content** — the delving's aid post as authored
   content (the wishbook's clinical daily loop made real): a room,
   a stock of dressings, patients arriving via the existing
   harm/hazard systems. *V2's stage; the health-cohort cut's set.*
5. **Fountain + honest acoustic profile** — one authored object
   with a real dB/frequency emission and a textbook-checkable fact
   chosen for the on-camera verification. *V4's opening prop.*
6. **Mobile-floor check** — verify the cockpit's minimal core on a
   real phone reads as the chat-app floor (stream + command bar +
   button bar), specifically with a *fight* and a *forum* session
   (the per-activity floor beat). Outcome: either "shootable as-is"
   or a scoped client punch-list. *V3's lunch beat; argument #7.*
7. **Rehearsed authoring path** — production prep, not a build: the
   camera-smooth click→type→script→write-room→publish walk for V5,
   with the protowizard-loop build-state caveat scripted honestly.
