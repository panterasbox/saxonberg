# trade-sugar

The sugar trade: dissolve, temper, skim, boil to the strike, and read the
thread. The boil itself is the kernel's latent-heat plateau (a solution's
boiling point climbs with its concentration, `Material.boilingPointElevation`);
what each stage becomes is an arrow on the material
(`Material.concentratesTo`). See `docs/subsystems/thermal.md`.
