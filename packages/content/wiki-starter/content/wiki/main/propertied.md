# Propertied {#propertied}

The capability of **carrying state somebody else put there** — a
per-instance bag of named values, for the things one subsystem needs to
hang on an object that another subsystem owns.

A quest flag. A buff. Whether you are inside a particular bank's
circle. It is deliberately open-ended, which is exactly why what
composes it matters.

## What must not {#what-must-not}

**Anything there is only one of.** A material, a species, a body plan,
a condition, a way of moving, a sense: each of those is *one instance
for the whole world*, shared by everything it describes. A value set on
oak is not a value about your plank — it is a value about oak, on every
oak there has ever been and ever will be. That is not per-instance
state; it is a global with a friendlier name.

⚠ Seven of them carried it until 2026-09-30, and nothing had ever
written one. The reason it was added is recorded and was a good one at
the time — per-material damage resistance, before there was a combat
system to read it — and when combat arrived it brought real fields
instead. The capability outlived the plan that wanted it.
