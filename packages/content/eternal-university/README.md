# eternal-university

The campus **locality pack** (residences D18): Duncan Hall — the dorm,
the residence ladder's first rung — and University Avenue, homed whole
out of the transitional world-seed. Package
`@saxonberg/content-eternal-university`; namespace root `/world/eternal`
(a locality pack's root is its extent, so the parked kernel classes kept
their paths when they moved into `src/`).

- `content/world/eternal/**` — the locality rows (Duncan Hall's warren,
  rooms, fixtures, Katie; the Avenue's crossing bundle) + the
  domain-local command views and controller templates.
- `src/**` — the classes those rows name (`DormWarren`, `DormRoom`,
  `DormDoor`, the provision controllers, Katie, the crossing
  instruments), mirrored on the rows (the lounge convention).
- `pack.yaml` — the `duncan-hall` group (Katie's conferred membership),
  the two Duncan Hall title claims, and the dorm-warren boot producer.
