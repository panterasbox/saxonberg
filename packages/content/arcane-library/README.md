# arcane-library

The `domain` kind: template rows under `content/obj/magic/` (the twelve `/obj/magic/Spell/<id>` rows and `/obj/magic/GlowlightOrb`, `/obj/magic/SparkSource`), adopted in place from the former `mud/seeds/obj/magic/` tree — 14 rows. The `SpellCatalogue` warms from `/obj/magic/Spell/` rows in `content` regardless of who wrote them. `SpellCatalogue.yaml`, `SpellsController.yaml` and `primer-of-glowlight.yaml` stay in `seeds/` (a registry, a controller, an item — not the library).
