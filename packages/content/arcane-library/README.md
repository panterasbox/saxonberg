# arcane-library

The `domain` kind: template rows under `content/obj/magic/` (the twelve `/stuff/idea/magic/Spell/<id>` rows and `/stuff/thing/magic/GlowlightOrb`, `/stuff/thing/magic/SparkSource`) — 14 rows. The `SpellCatalogue` warms from `/stuff/idea/magic/Spell/` rows in `content` regardless of who wrote them. `SpellCatalogue.yaml`, `SpellsController.yaml` and `primer-of-glowlight.yaml` stay in `seeds/` (a registry, a controller, an item — not the library).
