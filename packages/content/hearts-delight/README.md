# hearts-delight

The valley that feeds the city.

⚠ **No `src/`.** This pack ships content only — the `rejection` shape.
That is deliberate and load-bearing: a pack with a `src/` directory
registers a namespace root, and every class path under `/world/hearts-delight`
would then resolve into it and **throw** instead of falling back to the
kernel. `hinkley-hills` ships a `src/__tests__/` and nothing else, which
is exactly that footgun. This pack's tests are the wire drive.

⭐ **A static authored farm, not a managed one.** It does not run the
farming framework — it is content whose job is to feed the supply chain.
What makes it honest is that it is a source **node** rather than a
faucet: located (it costs the journey), seasonal (it costs the wait) and
finite (it can run out). The `distribution` counter is a faucet and is
honest precisely because it admits to being one.

The geography was already written down in the staged bible and nothing
had to be overridden: the flats are deep alluvium with senior water
rights and grow fruit; the upper bench is thin soil with junior rights.
Cereal is the low-value dryland crop, so the grain grows on the bench, as
the poor relation of the peaches.
