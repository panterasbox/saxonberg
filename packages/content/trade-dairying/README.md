# trade-dairying

The dairying trade: the setting pan, the churn, the cheese hoop (a
kernel `Mould`), the wheel (a kernel `Ripening` solid), and the profiles,
schedules, materials and recipes a cheese vat (the kernel's `Vat`) works
by. No verb, no controller, no Api — see `docs/subsystems/dairying.md`
and `docs/subsystems/mould.md`.
