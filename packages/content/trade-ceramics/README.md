# trade-ceramics

The ceramics trades — brick, tile, firebrick and pottery. See
`docs/subsystems/ceramics.md` (started in W3 of the ceramics build) and
`docs/plans/ceramics-plan.md` while the build is open.

Root `/trade/ceramics`. Nothing in this pack fires anything: firing is the
kernel's one rule (`ThermalMixin.kineticRecord` + `Material.kinetics`);
this pack ships the clays, the forms, the trade's goods and instruments, and
its people.
