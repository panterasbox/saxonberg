Stream tuning

One command surface for watching and following any live stream — Twitch or YouTube — driven straight from the cockpit's command bar. Every frame below is a real capture from the running app.

01

The front door

Sign in with Google or Twitch, drop in as a guest, or take the local dev door straight to a character. The cockpit opens on the ordinary world terminal.

02

Switch to the livestream layout

The video pane opens empty — and tells you exactly how to fill it. The old operator-curated broadcastSources picker is retired; the focal embed is now per-viewer state you drive with watch.

layout livestream-viewerlayout set to livestream-viewer
03

Watch a YouTube stream YouTube

Paste a link. The server resolves the target, stores it as your per-viewer cockpit.watch state, and pushes it to the client, which mounts the real player. No wizard config, no reader account — watching just works.

watch https://www.youtube.com/watch?v=dQw4w9WgXcQWatching YouTube dQw4w9WgXcQ.
04

Swap to Twitch — same verb Twitch

A second watch swaps the single focal embed to Twitch; the platform is inferred from the URL. The Twitch player's parent is the host domain, correct-by-construction. (This channel is offline, so it shows Twitch's own offline card — the embed path is what's on trial.)

watch twitch.tv/twitchWatching Twitch #twitch.
05

Follow chat with tune — and fail gracefully

Where watch is the single focal video, tune follows a stream's chat (many at once). Here it also shows two guardrails: a bare word that names no character points you at the platform flag, and an unconfigured relay degrades to a plain message instead of an error.

Found & fixed by driving the real app

Running it live — not just the unit suite — surfaced three integration bugs that pass-through tests can't see, because they exercise registration and wiring rather than a controller in isolation. All three are fixed and on the branch.

affordance
Verbs weren't offered to players. watch/tune shipped with no commandContributions, so a normal character got "I don't understand 'watch'." Added them to the Avatar's own console surface.
registration
Missing singleton template. The TwitchRelay → StreamRelay rename dropped the seed, so the chat path threw "Template not found: /obj/StreamRelay." Added the seed, matching the sibling in-memory singletons.
message
Dead-end reject. A bare watch shroud said only "Could not resolve that character" — now it points at --twitch/--youtube or a URL, the message shown above.
